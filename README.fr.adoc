= aloli-crystal/pdf-audit
:toc: left
:toc-title: Sommaire
:source-highlighter: rouge

Outil d'audit visuel pour PDFs. Quatre piliers : extraction de
manifest (baseline), diff entre baselines (régression visuelle),
détection d'anomalies typographiques (lint), génération de rapports
d'anomalies (annotate). Pure Crystal, zéro dépendance externe — repose
sur https://github.com/aloli-crystal/pdf2text[`aloli-crystal/pdf2text`].

== Quatre piliers

[%autowidth]
|===
| Pilier | Description

| `baseline`
| Extrait le manifest YAML d'un PDF : SHA-256, dimensions par page,
  mots avec leurs bbox. Sert de référence pour `diff` ultérieur.

| `diff`
| Compare 2 manifests (ou 2 dossiers de manifests) et liste les
  changements (bytes, pages, mots par page). Exit code 0 si
  identique, 1 sinon — utilisable en CI.

| `lint`
| Détecte 4 catégories d'anomalies typographiques :

  - `margin_overflow` : mot dépassant la marge droite attendue
  - `stuck_words` : mots chevauchants (gap négatif)
  - `huge_gap` : gap excessif entre 2 mots (justification cassée)
  - `orphan_punctuation` : ligne commençant par `.,;:!?»)]`

| `annotate`
| Génère un rapport texte structuré listant toutes les anomalies
  avec leur contexte (page, bbox, message, texte concerné).
  v0.1.0 produit du texte ; PDF overlay en v0.2.0.
|===

== Installation

[source,yaml]
----
dependencies:
  pdf-audit:
    github: aloli-crystal/pdf-audit
    version: "~> 0.1"
----

== Utilisation CLI

[source,bash]
----
# Extraire le manifest d'un PDF
pdf-audit baseline document.pdf -o baseline.yml

# Comparer 2 manifests (régression visuelle)
pdf-audit diff baseline.yml after.yml
pdf-audit diff baseline-dir/ after-dir/

# Détecter les anomalies typographiques
pdf-audit lint document.pdf
pdf-audit lint document.pdf --margin 36 --max-gap 20

# Générer un rapport texte des anomalies
pdf-audit annotate document.pdf -o report.txt

# Aide
pdf-audit help
pdf-audit help <command>
----

== Utilisation programmatique

[source,crystal]
----
require "pdf-audit"

# Manifest YAML
manifest = PdfAudit::Manifest.from_pdf("doc.pdf")
File.write("baseline.yml", manifest.to_yaml)

# Lint
opts = PdfAudit::Linter::Options.new(right_margin_pt: 36.0, max_gap_pt: 20.0)
findings = PdfAudit::Linter.lint(manifest, opts)
findings.each do |f|
  puts "p#{f.page} [#{f.kind}] #{f.message}"
end

# Diff
baseline = PdfAudit::Manifest.from_yaml(File.read("baseline.yml"))
diff = PdfAudit::Differ.diff(baseline, manifest)
puts "Régression!" unless diff.identical
----

== Architecture

----
src/
├── pdf-audit.cr              # require global
├── pdf_audit/
│   ├── version.cr
│   ├── manifest.cr           # Manifest YAML/JSON serializable
│   ├── differ.cr             # Compare 2 manifests
│   ├── linter.cr             # 4 règles d'anomalies
│   └── annotator.cr          # Rapport texte
└── cli.cr                    # 4 sous-commandes + help [<sub>]
----

Le manifest est une structure typée `PdfAudit::Manifest` qui inclut
`YAML::Serializable` + `JSON::Serializable`, donc round-tripable dans
les deux formats. Le linter retourne un `Array(Linter::Finding)`
avec position et type d'anomalie ; sérialisable en JSON via
`finding.to_h.to_json`.

== Convention de versioning ALOLI

`pdf-audit` est une **création originale** (pas un portage d'une
gem Ruby), donc le numéro de version est en **3 chiffres SemVer
classique** : `0.1.0` → `0.2.0` → … → `1.0.0`.
Voir `feedback_versioning_shards.md` (mémoire ALOLI).

== Dépendances

* `aloli-crystal/pdf2text ~> 0.3` — extraction texte + bbox
* `aloli-crystal/pdf ~> 1.2` (planifié pour v0.2.0 — PDF overlay)
* Stdlib Crystal : YAML, JSON, Digest::SHA256

Pas de dépendance externe au runtime (poppler-utils non requis) —
`pdf-audit` peut tourner dans tout environnement Crystal, y compris
CI Alpine et Docker minimal.
