= aloli-crystal/pdf_audit
:toc: left
:toc-title: Contents

Visual audit toolkit for PDFs : baseline/diff/lint/annotate. Consumes aloli-crystal/pdf2text.

== Install

[source,yaml]
----
dependencies:
  pdf_audit:
    github: aloli-crystal/pdf_audit
    version: "~> 0.1"
----

== Quickstart

[source,crystal]

require "pdf_audit"
