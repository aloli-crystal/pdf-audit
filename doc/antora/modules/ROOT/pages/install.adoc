= Installation

== Comme dépendance d'un autre shard

Ajoutez à votre `shard.yml` :

[source,yaml]
----
dependencies:
  pdf_audit:
    github: aloli-crystal/pdf_audit
    version: "~> 0.1"
----

Puis :

[source,shell]
----
shards install
----

== En local pour développer

[source,shell]
----
git clone git@github.com:aloli-crystal/pdf_audit.git
cd pdf_audit
shards install
crystal spec       # lancer les tests
----
