= Utilisation

== Cas d'usage principaux

[source,crystal]
----
require "pdf_audit"

# Exemple : à remplir lors de l'écriture du shard.
----

== En CLI (si applicable)

[source,shell]
----
pdf_audit --help
pdf_audit help
pdf_audit help <sous-commande>
----

Convention UX ALOLI : tout CLI accepte `<cmd> help [<sub>]` en
positionnel (équivalent à `--help`/`-h`, focus sur une
sous-commande quand un argument est fourni).
